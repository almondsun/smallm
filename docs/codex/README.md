# Codex Helper Files

This directory contains repository-specific guidance for Codex sessions working
on `smaLLM`.

Use these files with the repo-root `AGENTS.md`:

- [`architecture.md`](architecture.md): subsystem boundaries, data flow, and
  artifact contracts.
- [`build-and-test.md`](build-and-test.md): canonical validation commands and
  risk-based validation matrix.
- [`experiments.md`](experiments.md): rules for experiment milestones,
  reports, runtime artifacts, and interpretation.

These files are operational guidance. Human-facing project documentation lives
in `README.md` and `docs/`.
