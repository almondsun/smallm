# Data

Raw and processed corpus files are local runtime data.

- `data/raw/input.txt` is local raw text and is ignored by git.
- `data/processed/corpus.txt` is generated from raw text and ignored by git.
- `data/processed/corpus_stats.json` is generated metadata and ignored by git.
- `data/processed/corpus_manifest.json` is generated source, checksum, and normalization metadata and ignored by git.
- `data/processed/tokenizer.json` is generated by tokenizer preparation and ignored by git.

Training copies `data/processed/corpus_manifest.json` into each run directory as
`dataset_manifest.json` and records key dataset identity fields in `summary.json`.

Reproduce the current data preparation step with:

```bash
python scripts/prepare_corpus.py \
  --input data/raw/input.txt \
  --output data/processed/corpus.txt \
  --stats data/processed/corpus_stats.json \
  --manifest data/processed/corpus_manifest.json \
  --source-name "Alice-style public-domain prose excerpt"
```
